Política de Privacidade

Atualizada em 24 de novembro de 2026.

O Hypercut é uma ferramenta pessoal do canal HRochaTV, que roda no computador do próprio criador. Esta política explica quais dados ele usa e como.

Dados do Google e do YouTube

Quando o criador conecta o canal, o Hypercut pede ao Google acesso a:

  • Enviar vídeos (youtube.upload): para publicar no canal os cortes que o criador aprovou.
  • Ver a conta do YouTube (youtube.readonly): só para mostrar o nome, a foto e o número de inscritos do canal conectado.

O Hypercut não lê vídeos, comentários, mensagens, dados de inscritos nem de outros canais, e não usa esses dados para publicidade, perfis ou treinamento de IA.

Onde os dados ficam

O acesso concedido pelo Google (token) fica guardado apenas no computador do criador, criptografado pelo próprio Windows. Não existe servidor do Hypercut recebendo esses dados. Os vídeos e textos são enviados direto do computador do criador para o YouTube.

Compartilhamento

Nenhum dado é vendido, compartilhado ou transferido a terceiros.

Uso Limitado

O uso e a transferência de informações recebidas das APIs do Google pelo Hypercut seguem a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

YouTube e Google

O Hypercut usa os Serviços de API do YouTube. Ao usá-lo, você concorda com os Termos de Serviço do YouTube. A Política de Privacidade do Google também se aplica aos dados tratados pelo YouTube.

Como revogar o acesso

Dá para desconectar o canal no próprio Hypercut (Contas e redes → Desconectar), o que apaga o token do computador, ou revogar o acesso a qualquer momento em myaccount.google.com/permissions.

Privacy Policy (English)

Last updated: November 24, 2026.

Hypercut is a personal tool of the HRochaTV channel that runs on the creator's own computer. When the creator connects his YouTube channel, Hypercut requests the youtube.upload scope (to upload the clips he approves to his own channel) and the youtube.readonly scope (only to display the connected channel's name, picture and subscriber count). It does not read videos, comments, messages, subscriber data or any other channel, and it does not use Google user data for advertising, profiling or AI training.

The OAuth token is stored only on the creator's computer, encrypted with Windows DPAPI. There is no Hypercut server receiving this data; videos and metadata go directly from the creator's computer to YouTube. No data is sold, shared or transferred to third parties.

Hypercut's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Hypercut uses YouTube API Services. By using it you agree to be bound by the YouTube Terms of Service; see also the Google Privacy Policy. Access can be revoked at any time in Hypercut (Accounts → Disconnect) or at myaccount.google.com/permissions. Contact: hygor.k92@gmail.com.
